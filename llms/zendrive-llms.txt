# Zendrive

> Zendrive Inc. was a San Francisco mobility risk intelligence company that measured driving
> behavior from ordinary smartphone sensors. Its product was a mobile SDK, not an HTTP API:
> an app embedded the Zendrive SDK, the SDK detected the start and end of every drive,
> collected accelerometer/gyroscope/GPS data with minimal battery impact, and uploaded it to
> Zendrive for scoring — collision detection, distracted driving, speeding, phone handling —
> which fleets and auto insurers consumed through a dashboard and an Analytics REST API.
> Intuit announced on 2024-06-13 that it would acquire Zendrive's technology for Credit
> Karma's usage-based auto insurance product, Karma Drive, taking on Zendrive's CEO and
> co-founder/CTO. The developer program was shut down afterwards.

## Status (probed 2026-09-05)

- The developer program is END OF LIFE. No new integration is possible.
- zendrive.com and www.zendrive.com have NO DNS A record. Nothing answers on HTTP.
- developers.zendrive.com, app.zendrive.com, api.zendrive.com, iql.zendrive.com and
  status.zendrive.com are NXDOMAIN.
- docs.zendrive.com is a dangling Cloudflare CNAME: every path returns HTTP 403 with the body
  "error code: 1014" (CNAME Cross-User Banned). It is not documentation, it is an edge error.
- No OpenAPI, Swagger, GraphQL SDL, AsyncAPI, agent card, llms.txt, MCP server or
  /.well-known/ document is served on any reachable Zendrive host.
- SDK setup validates the application key against Zendrive's servers over the network, and no
  new application key can be obtained, so the surviving binaries below cannot be initialized.

## Integration model

- Authentication: a single opaque `applicationKey` (SDK key) plus a caller-chosen `driverId`,
  both required in `ZendriveConfiguration` and validated at
  `+[Zendrive setupWithConfiguration:delegate:completionHandler:]`. No OAuth, no scopes.
- Data residency: `ZendriveConfiguration.region` is `ZendriveRegionUS` (default) or
  `ZendriveRegionEU`, fixed at setup and changeable only after `wipeOut`.
- Events arrive as in-process delegate callbacks (`ZendriveDelegateProtocol`), not webhooks.
- Errors are `NSError` in `kZendriveErrorDomain`; 23 codes are published.
- Insurance periods 1/2/3 are modelled directly (`ZendriveInsurance`,
  `ZendriveInsurancePeriod`) for rideshare/TNC coverage.
- Testing is simulation, not a hosted sandbox: the `ZendriveSDK-testing` Maven artifact, the
  `Mock-ZendriveSDKDemo` iOS target, "Simulate Preset Drives", and `ZendriveMockAccidentConfig`.

## Notes for agents

- Do not attempt to call a Zendrive API. There is no reachable host.
- Do not confuse Zendrive with Fairmatic (founded by Zendrive's original founder, now
  redirecting to leeoinsurance.com), with Damoov/Telematics SDK, or with Zendesk.
- github.com/caarbon/zendrive and github.com/fleetio/zendrive are third-party wrappers of the
  retired Analytics REST API. They are not published by Zendrive.
